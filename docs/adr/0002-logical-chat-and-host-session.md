# ADR 0002：逻辑入口与宿主会话的权威边界

日期：2026-10-24。状态：IMPLEMENTED_NOT_VERIFIED（真实多轮验证另记）。

工作台 chat_messages 是逻辑入口的可见对话记录，包含用户输入、确定性建卡/停止回执及后台成果。宿主会话保存 Agent 执行上下文、工具事件、原生权限交互；不能把它当作完整的工作台对话投影。任务/Run/Result 的权威仍是工作台领域库。

每次宿主调用附加有界工作台状态与最近 10 条入口消息；排除刚保存的当前消息 ID。历史以资料标注，不作为新 prompt 逐条重放；本轮用户输入保持独立。历史 JSON 上限 5000 字符，每条至多 1000，状态使用既有 1500 token 启发式预算。宿主原生压缩仍负责其执行历史，这些限制不代表整个宿主 system prompt 的总 token 上限。

新建或恢复宿主会话走同一投影流程。确定性命令和成果因此能被下一轮指代；这不是完整长期记忆。超过窗口的决定检索、持久 pending 迁移和宿主超时后晚到回复回流仍待实现。

已选择宿主路径后，错误/未知受理不得自动再投另一模型。仅能力缺席时保留显式能力披露的文本降级路径，避免受理后 ACK 异常导致重复副作用。

回滚只涉及 context.ts/index.ts 与测试，无数据库迁移。宿主会话中的原始工具审批目前未统一投影到工作台，不能据“原生提问可用”宣称主入口权限交互已完成。
